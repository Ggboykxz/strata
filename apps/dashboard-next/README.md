# @strata/dashboard-next

Read-only Next.js (App Router) display of the dashboard view generated by
`@strata/dashboard`.

## Data flow

1. `pnpm --filter @strata/dashboard build` writes `apps/dashboard/dist/data.json`.
   That builder remains the single source of truth; this app never reads repo state.
2. The server component in `app/page.tsx` reads that artifact at build time through
   `lib/dashboard-view.ts` (`path.resolve(process.cwd(), '../../apps/dashboard/dist/data.json')`).
   The route is `force-static`, so it is prerendered by `next build`.
3. All ten view groups are rendered as plain HTML tables. Values are displayed with a
   `renderValue` equivalent (`null`/`undefined` → `NOT COMPUTABLE`). There is no client
   component, no fetch, no auth and no gameplay state; the page is deterministic given
   `data.json`.

Run `pnpm --filter @strata/dashboard-next dev` for local viewing or
`pnpm --filter @strata/dashboard-next build && pnpm --filter @strata/dashboard-next start`
for the prerendered page. The `next`, `react` and `react-dom` dependencies are installed
from the workspace root.
