**Why 12 workflows are manual-only.** Their validator is still a declared P0-002 stub that exits 1. A
workflow that calls a stub on every PR would make CI permanently red for a condition nobody can fix yet;
making it manual is honest. The validator rejects any such workflow that is not `workflow_dispatch`-only,
so the exemption cannot spread by accident.

**Not executed.** GitHub Actions cannot run from this sandbox. All evidence is static validation; CI runs
only after this branch is pushed and the Director opens/merges the PR. No claim is made that a job passed.
